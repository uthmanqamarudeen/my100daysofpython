# Day 27: Tkinter & GUI Programs

## Objectives
- Learn to build **Graphical User Interfaces (GUIs)** with **Tkinter**.
- Understand Tkinter widgets: `Label`, `Button`, `Entry`.
- Master layout managers: `pack()`, `grid()`, `place()`.
- Handle user input and button clicks.

## Key Concepts

**Tkinter Basics:**
- `Tk()` - Create window
- `Label()` - Display text
- `Button()` - Clickable button with `command` parameter
- `Entry()` - Text input field
- `grid()` - Position widgets in rows/columns

## Projects

### 1. Basic GUI Demo (`main.py`)
- Simple window with labels, buttons, and text entry.
- Demonstrates event handling and widget configuration.

### 2. Mile to Kilometer Converter
- Practical GUI application for unit conversion.
- Input miles → Click "Calculate" → Output kilometers.
- Uses grid layout for clean positioning.

## How to Run
```bash
cd mile-to-km-converter
python main.py
```

**Note:** This is your first GUI! From here, you can build desktop apps with Python. 🖥️
